# HR Attrition Analysis 👥

## Overview
Analysed 1,470 employee records from IBM HR Analytics 
dataset using SQL to identify key attrition patterns 
across departments, age groups, salary bands and job roles.

## Tools Used
- MySQL Workbench (SQL Querying)
- Microsoft Excel (Charts & Summary)

## Key Findings
- Overall attrition rate: 16.12% (237 out of 1,470 employees)
- Employees under 25 had highest attrition at 39.18%
- Sales department had highest attrition at 20.63%
- Low salary employees (below 3K) had 3x higher attrition 
  than top earners (28.61% vs 8.90%)
- Sales Representatives had highest role-level attrition 
  at 39.76%
